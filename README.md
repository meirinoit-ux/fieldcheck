# אפליקציית ביקורי אתר 🏗️

## הוראות העלאה ל-Vercel (5 דקות)

### שלב 1 — GitHub
1. כנסי ל-[github.com](https://github.com) וצרי חשבון חינמי (אם אין)
2. לחצי על **"New repository"** (הכפתור הירוק)
3. שם: `site-inspector`
4. לחצי **"Create repository"**
5. גררי את כל התיקייה הזו לחלון GitHub (או לחצי "uploading an existing file")
6. לחצי **"Commit changes"**

### שלב 2 — Vercel
1. כנסי ל-[vercel.com](https://vercel.com)
2. לחצי **"Sign up"** → **"Continue with GitHub"**
3. לחצי **"Add New Project"**
4. בחרי את `site-inspector` מהרשימה
5. לחצי **"Deploy"** — זהו!

### תוצאה
תקבלי קישור כמו: `https://site-inspector-xxx.vercel.app`

שלחי את הקישור הזה לכל מי שצריך גישה — עובד בטלפון כמו אפליקציה רגילה!
